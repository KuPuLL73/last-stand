# Основа 3D-арены

Выбран **Three.js 0.186.1 + JavaScript**, сборка **Vite 6.4.4**. Three.js отвечает за 3D-рендеринг через WebGL, а управление, попадания и правила арены реализуются в игровом коде. Это подходит небольшой браузерной игре: уже созданная Шелли загружается как GLB с анимациями, нет отдельного тяжёлого экспорта из другого движка, итоговая сборка состоит из обычных статических файлов.

Яндекс Игры [поддерживают WebGL](https://yandex.ru/dev/games/doc/ru/console/add-new-game.html). Одобряется готовая игра, а не название её движка: обязательны SDK, корректное управление и выполнение [требований платформы](https://yandex.ru/dev/games/doc/ru/concepts/requirements). Там же пункт 3.5 требует права на распространяемые материалы; выбор Three.js сам по себе не гарантирует одобрение игры с персонажами Brawl Stars. Текущая арена — тест ходьбы и стрельбы, а не заявка на публикацию.

## Подключение платформы

`platform.js` экспортирует `createPlatform()`. На localhost и адресах локальной сети он работает без сетевого запроса SDK. При размещении архива на Яндексе динамически загружает `/sdk.js`, затем вызывает `YaGames.init()` по [официальной инструкции](https://yandex.ru/dev/games/doc/ru/sdk/sdk-about). Для отдельного внешнего хостинга путь SDK следует настроить согласно той же инструкции.

```js
const platform = await createPlatform();
const language = platform.language;
platform.onPauseChange(paused => {
  // Остановить/возобновить симуляцию и звук; сбросить удержанные кнопки.
});
// После загрузки модели, арены и установки обработчиков управления:
platform.markReady();
platform.setGameplay(true);
// При открытии собственного меню/паузы: platform.setGameplay(false).
```

`markReady()` однократно сообщает реальную [готовность игры](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events). `setGameplay()` отмечает начало/остановку игры. `onPauseChange()` сразу сообщает текущее состояние и возвращает функцию отписки; учитываются скрытие вкладки, потеря фокуса и [события SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-events), включая стартовую рекламу. Во время паузы игровой код должен останавливать и симуляцию, и звук. SDK уже размечает геймплей при своих pause/resume, bridge сохраняет пользовательскую паузу отдельно.

`language` получает [язык платформы](https://yandex.ru/dev/games/doc/ru/sdk/sdk-environment) через `environment.i18n.lang` после инициализации; автономный тест использует язык браузера. Также доступны `paused`, `standalone`, `sdk`, `sdkError` и `destroy()`. Ошибка загрузки SDK не блокирует локальную механику и доступна через `sdkError`; наличие автономного режима не означает успешную интеграцию на Яндексе.
