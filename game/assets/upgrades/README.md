# Иллюстрации карточек улучшений

18 иллюстраций, рамка и звезда созданы встроенным ImageGen по концептам Gemini пользователя и мотивам новых комбо. Исходные PNG хранятся в этой папке. Игровые WebP сохраняют прозрачность и вместе весят 1 455 792 байта. Названия, бонусы и звёзды ранга рисует компонент `game/upgrade-cards.js`.

Промпты и файлы генерации описаны в [общих иллюстрациях, рамке и звезде](../../../reference/upgrade-art-common-prompts.md), [оружейных иллюстрациях](../../../reference/upgrade-art-weapons-prompts.md), [иллюстрациях эффектов](../../../reference/upgrade-art-effects-prompts.md) и [иллюстрациях комбинаций](../../../reference/upgrade-combo-art.md).

После замены PNG запустить `node game/tools/export-upgrade-art.mjs` из корня игры. Экспорт проверяет размеры и прозрачность. Общий лист переснимается командой `node game/tools/capture-upgrade-review.mjs` при работающем dev-сервере на 5190.
