# Последний рубеж

Браузерная 3D-игра на выживание. Выбери Стива или Шелли, отбивайся от волн врагов и собирай улучшения во время забега.

- **Кампания** — четырёхминутный пролог «Первый разлом» с финальным боссом.
- **Соло** — бесконечные волны с шестью боссами и двумя картами.
- **Развитие** — 17 видов оружия Стива, три боевые комбинации, магазин и локальные рекорды.

## Локальный запуск

Нужен Node.js 20.12 или новее.

```sh
npm ci
npm run dev
```

Открой [игру](http://127.0.0.1:5190/survival.html). Чтобы собрать проект, выполни `npm run build`.
